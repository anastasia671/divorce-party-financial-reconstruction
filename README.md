# Divorce Party International Ltd. — Financial Reconstruction

Static assessor-facing financial reconstruction at 31 August 2026.

The deployed application provides:

- evidence hierarchy and 100-decision register;
- supporting schedules and reconciled financial statements;
- material uncertainty and board recommendation; and
- the machine-readable certified answer at `/submission.json`.

The static deployment output is the `dist/` directory. No login, database, or external API is required.
